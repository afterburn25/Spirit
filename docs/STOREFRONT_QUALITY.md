# Populated storefront quality — dev12 checkpoint

Verification pending on work/storefront-quality. This pass corrects a real multi-photo regression: the old script replaced img.src but retained the previous responsive srcset, so the browser could keep displaying the original photograph. The replacement switches an entire decoded image from a server-rendered inert template, preserving its own sizes/srcset/dimensions/alternative text. The previous image stays visible on failure; superseded requests cannot replace the latest selected image.

Selections keep focus, quantity, variant controls, canonical metadata and audio node. Native same-product links choose an approved-array position when JavaScript is disabled. No arbitrary media ID from a query becomes authorization. Photo changes replace the current history entry rather than producing a new Back entry for each thumbnail. A72px thumbnail display hint reduces oversized candidate selection. No-JavaScript navigation performs a normal new request and does not promise preservation of unsaved form fields or continuous audio across that full navigation.

New tests create actual published synthetic merchandise via owner forms, then use Chromium/Firefox/WebKit at1440/390/320 and a no-JavaScript390px case. They inspect the real decoded currentSrc, failed requests, out-of-order completion, alternative text/dimensions, focus, audio navigation, history, form values and withdrawal of unpublished originals/derivatives. Existing full suites remain mandatory. Test images are not real merchandise and must never be seeded into deployment packages.

A Playwright engine on Linux is not a physical iPhone, Android or full native Safari acceptance test. Actual A2/provider/artwork/content and final owner acceptance remain separate.
